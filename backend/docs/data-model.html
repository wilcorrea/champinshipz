Championshipz — modelo de dados

Três coleções guardam tudo: teams (times globais, reaproveitáveis), championships (liga ou copa, com os participantes embutidos) e matches (os jogos). A classificação nunca é salva — é calculada a partir dos matches.

As três coleções

teams collection

Time global (name, code). Cadastrado uma vez e reaproveitado em vários campeonatos.

championships collection

type define LEAGUE ou CUP. Os participantes ficam embutidos como uma lista de Participant (teamId + group).

matches collection

Cada jogo referencia o campeonato (slug) e os times (homeTeamId/awayTeamId). stage separa grupo de mata-mata.

Participant, ChampionshipType e MatchStage não são coleções — vivem dentro dos documentos. As setas tracejadas cruzam coleções por id/slug (não há join automático no Mongo; a junção acontece no serviço de standings).
